OpenTail.Stingray is a high-performance local inference engine built for running large language models, vision-language models, and diffusion-based generative AI on commodity hardware. The CPU execution path uses hand-tuned AVX2 and FMA SIMD kernels for all quantization formats including Q4_K, Q5_K, Q6_K, Q8_0, FP16, and BF16, achieving near-theoretical memory bandwidth utilization during matrix-vector multiply operations. Speculative decoding is implemented natively via DSpark, EAGLE-3, and Multi-Token Prediction, delivering between 1.8 and 3.2 times inference speedup while maintaining byte-identical output with standard autoregressive decoding. Vision encoding supports more than fifteen vision transformer architectures including Gemma 4, Llama 4 Scout, Qwen2-VL, MiniCPM-V, CogVLM, PaddleOCR, IBM Granite 4, GLM4-V, InternVL3, LLaVA, and Pixtral. The KV cache supports paged allocation, session forking, TurboQuant compression, and SnapKV eviction for managing long-context inference up to 128 thousand token context windows on consumer hardware. The engine is written entirely in C# targeting .NET 10 and exposes an OpenAI-compatible HTTP server, a command-line interface, and a session management API for multi-turn conversational applications.
