Written after [plan 4](2026-11-01-plan-4.md) ran out of items that need no checkpoint, reference or decision. Source: the open boxes in `docs/` outside `docs/done/` that plans 3 and 4 did not take
(about 385 unticked when this was written; `00-current-work.md` 47, the TTS/ASR GPU residency checklist 31, the OpenTelemetry plan 22, `todo.md` 21, `103-quickest-first-plan.md` 21,
diffusion performance 19). Plan 4's rule stands: keep a box only if it names a failure, a user-visible limitation, a measurable gain or a recurring cost, can be verified on this machine
(Ryzen 7 5700G, 63 GiB, iGPU only) and was **checked against the code first**. Rules in force: no subagents; never `git add -A`; `Tests.Core` before merging; mutation-check new tests;
timed real-weight runs; perf on a quiet machine, interleaved A/B, 3+ runs; rule 13 (an iGPU result says nothing about a discrete GPU); one merged PR per item.

Contracts this must satisfy: the test floors in `.github/workflows/ci.yml`; the `ArchitectureFacts.txt` baseline (regenerate only with the reason in the commit); `StatusMatrixCitationTests` and
`DocumentationLinkTests` (every STATUS citation and relative link must resolve); STATUS rows are sourced (CLAUDE.md rule 10); "ported, not verified" families stay internal (rule 14).

- Transcription `model` field selecting a pipeline: recommend **yes, minimal**. The server's other routes already choose by name; keep one default and answer 400 for an unknown id.
- Stop the Qwen3-Coder NaN hunt: recommend **yes**, keep a one-line canary in the Vulkan hybrid MoE test and reopen only if it fires again.
- HTTP image endpoints on the real pipelines (plan 3 Q7): recommend **not now**. They are 501 and honest; wiring them needs async job handling and a model memory policy that nobody has asked for.
- Qualify the speak and transcribe recipes: run `pwsh scripts/qualify-tasks.ps1 -AcceptLicence` once yourself (it accepts the research-only Piper voice licence).
- Cut a release (1.0.10): everything merged since 1.0.9 (Vulkan hybrid scale fields, later-turn handoff, the API fixes, Gemma 1) is unpublished. Recommend **yes** after C is done, because the telemetry
  claims are the most-quoted part of the README.
- D1 design (duplicate versus unify KV ownership): recommend **duplicate first**.
