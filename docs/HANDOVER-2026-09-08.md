## Real, committed progress this session (chronological, newest last)

- **MarbleNet VAD** and **Citrinet ASR**: two brand-new models ported from scratch, both exact
  golden-parity matches against the reference CLI on the first real attempt. Fully done.
- **MOSS-TTS-Nano loudness bug**: found and fixed a real bug — every listenable sample was
  greedy-decoded (argmax) instead of using the reference's real sampling defaults
  (`temperature=1.7, top_p=0.8, top_k=25`). Fixing it closed the spectral-content gap (ZCR) from
  ~54% off to ~7% off the reference. A separate ~2.7x loudness (RMS) gap was then **fully
  root-caused and formally accepted**: fed the reference's own real generated codes into this
  port's codec decoder and got an exact RMS/peak match, proving the decoder itself is correct — the
  gap is an RNG mismatch (`std::mt19937`/`discrete_distribution` vs .NET `System.Random`), not
  fixable without replicating MSVC STL internals bit-for-bit. **BUT**: applying that same real
  sampling fix to the two LONGER/more complex samples produced gibberish, not just quiet audio —
  this is the live regression Antigravity is bisecting now (see above). The short zero-shot sample
  got noticeably better; something about longer generation or the voice-cloning path did not.
