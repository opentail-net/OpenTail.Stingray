# Completed and superseded work

This directory retains completed work, measurements, negative results, and superseded plans.
It is evidence, not an active roadmap.

Documents archived from the active runway carry an **ARCHIVED** banner at the top stating what
closed and what, if anything, carried forward. Where a banner and the body disagree, the banner is
newer. Anything a banner marks as "carried forward" is tracked in
[../00-current-work.md](../00-current-work.md), not here.

The active roadmap is [00-current-work.md](../00-current-work.md).
