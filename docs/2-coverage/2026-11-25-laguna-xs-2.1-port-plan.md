## Branch map (llama.cpp `laguna.cpp` → this engine)

| llama.cpp branch | Engine | Status |
|---|---|---|
| `n_head(il)` array (`attention.head_count`) | `ModelHyperparams.LayerNumHeads` (new), set by `LagunaArchitecture.ApplyLaguna` from `ctx.IntArray`; `NumHeads` = max (64) for the scratch buffers | **new**, applied only through the Laguna semantics |
| `qDimL = n_head_il * head_dim` in attention, RoPE, QK-norm, temperature scale, per-head gate, output projection | `ForwardPass.Decode.cs` uses `layerHeads` in every site; `ForwardPass.Attention.cs` `Attention(..., numHeadsL)` (default = model count) | **new** (per-layer), other families unchanged |
| QK-norm before RoPE (`attn_q_norm` / `attn_k_norm`) | `ApplyQkNormLayer(..., qHeads)` now takes the layer's query-head count | **changed** (default keeps old behaviour) |
| `n_rot_l`: full = 64, SWA = 128; YaRN on full, plain on SWA | `RopeWidthPerLayer` + `LayerRopeDim` = [64 full, 128 SWA]; `RopeThetaSwa` = 10000; YaRN on the global table from the existing `rope.scaling` handling | reused (SWA plain table already exists) |
| `is_swa_il`: full when `i % 4 == 0` | semantics sets `IsSwaLayer[i] = i % 4 != 0` directly (GatedSwa's default pattern would be wrong) | set in semantics |
| Attention gate: `softplus(wqkv_gate · attn_inp)`, one value per head, broadcast over head_dim before `wo` | `AttentionOutputGateSoftplus` (new) selects `SoftplusInPlace` in the per-head gate path (`ForwardPass.Decode.cs`) | **new** |
| `build_inp_embd` (no MuP scale) | `EmbeddingScale = 1` | override |
| MoE: sigmoid routing, `exp_probs_b` bias, sum-norm, routed scale 2.5, one SiLU shared expert, layer 0 dense | the afmoe/lfm2moe path already reads `expert_gating_func`, `expert_weights_scale`, `LeadingDenseBlockCount`, shared width; `NormalizeMoeTopKWeights = true` set in semantics | reused (to confirm by the golden) |
| NEOX RoPE (rope-type group includes `LLM_ARCH_LAGUNA`) | `UsesNeoxRope = true` | set |
| Tokenizer `laguna`: `[^\n]+|[\n]+`, then the Qwen-2 cascade (`llama-vocab.cpp`, pre-type `LAGUNA`) | `PreTokenizerPatterns`: `laguna` → `[LagunaLines, Qwen2]`; `LagunaLines` is new | **new** |
