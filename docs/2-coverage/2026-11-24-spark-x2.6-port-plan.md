## Verification so far

1. **Structural/synthetic (level 1–2).** `Spark25SyntheticTests`: 2 of 2 pass. Hyperparameter test checks the flags, per-layer RoPE widths and SWA pattern. Forward test runs 8 tokens through a 4-layer synthetic model and compares logits with an in-test reference written from the llama.cpp rules. Measured worst logit delta: **2.1e-4** (position 4; position 0 is 1.3e-7), tolerance 5e-4. The residual is probably the engine's approximate `exp` (`SimdKernels.ExpApprox256`, used in softmax and GELU), which is not verified. Full-model equality to a real llama.cpp build is not claimed.
2. **Bug found and fixed by the test.** Before the `RopeWidthPerLayer` change the forward pass rotated 8 channels on SWA layers (the global `RopeDim`), not 16. Position 1 diverged by 5.8e-4. The fix is flag-gated so no other family changes.
3. **Contract tests** (`tests/OpenTail.Stingray.Tests.Core`): `ArchitectureFacts_MatchBaseline` passes after the one-line regeneration. `EveryDescriptor_EvidenceDocExistsOnDisk` passes once this file exists. `ArchitectureLiterals_OutsideTheArchitectureFolder_OnlyShrink` failed (`PreTokenizerPatterns.cs` 26 → 28: the new `"spark2_5"` case and KnownPreTypes entry). Resolved 2026-11-24 by the owner's choice: the literal baseline was regenerated with that reason (the string is the GGUF `tokenizer.ggml.pre` value, not an architecture id in engine code). All three architecture guard classes now pass (11/11, 31/31, 14/14).
4. **Real checkpoint smoke (not parity).** `stingray admit-arch` on the real file: loads, runs a forward pass, returns 8 greedy tokens with no error (the tokens were not compared with any reference). `stingray -m … -p "The capital of France is" --temp 0 -g -1` (with `STINGRAY_DIAGNOSTIC_ALLOW_UNSUPPORTED_ARCH=1`) produced coherent text: "…Likely Paris… Paris." (72 prefill tokens, 12.8 t/s prefill, 12.8 t/s decode, CPU only). This shows the model is not producing noise, not that the logits match the reference.

## Deltas from Muse-Glimmer / afmoe (why the flags exist)

| Feature | Muse-Glimmer, afmoe (admitted) | Spark-X |
|---|---|---|
| attention gate | per element, `[embDim → numHeads·headDim]` | per head, `[embDim → numHeads]` |
| RoPE width | global `RopeDim` | per layer: 64 full, 256 SWA |
| RoPE on | SWA layers only (Muse; afmoe too) | every layer |
| embedding scale | afmoe sqrt(embDim), Muse none | none |
| FFN | SwiGLU (SiLU) | approximate GELU, parallel gate/up |
| tokenizer pre-type | afmoe's own pattern (admitted); Muse-Glimmer not checked | `spark2_5` |
