## Branch map (llama.cpp → this engine)

| llama.cpp branch | Engine | Status |
|---|---|---|
| Single-sublayer dispatch: MoE layer = FFN-only block (kv 0, ff > 0) | `HybridFfnOnlyLayer` (existing); the FFN-only branch of `ForwardPass.Decode.cs` now calls `MoeFfn` when `IsMoeLayer(layer)`, else `DenseFfn` | **changed** |
| Router: `router_logits = ffn_gate_inp · cur` on the full-width input; sigmoid gating with `exp_probs_b` selection bias | `MoeFfn` router (existing); `ExpertGatingFunc = 2` set in the descriptor semantics | reused |
| Experts: `build_moe_ffn(inp_latent, ..., gate = nullptr, ..., RELU_SQR)`: up → relu² → down, no gate | `MoeFfn` sequential loop, non-gated branch (`gatedExperts` = gate tensor present) | **new** |
| Latent: `inp_latent = ffn_latent_down · cur`; experts run on it; `moe_out = ffn_latent_up · moe_out` | `_wLatentDown` / `_wLatentUp` (new), latent buffers `_latentIn` / `_latentOut`, applied inside `MoeFfn` when `_latentDim > 0` | **new** (used only if the tensors exist) |
| Shared expert: `build_ffn(inp_emb, up_shexp, relu², PAR)` with no gate | `MoeFfn` shared branch, non-gated when `ffn_gate_shexp` is absent | **new** |
| Output: `cur = moe_out + ffn_shexp` | `MoeFfn` step 4 (unchanged) | reused |
| No RoPE on attention blocks; no embedding scale | `NoRopeLayerStep = 1` (as `nemotron_h`) | reused |
| Batched prefill | `_perTokenTrunkOnly` set for hybrid MoE layers, so prefill runs per token through `MoeFfn` | **new** |

Tensor loading: `TryResolveTensor` returns an empty reference for absent tensors, so a missing gate (`ffn_gate_exps`, `ffn_gate_shexp`) selects the non-gated path instead of failing the load.
